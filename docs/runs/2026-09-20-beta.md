## 1. Config diff vs alpha

`config.json`: `embed_dim` 1024 (alpha 512), `scaler_eps` 0.01 +
`scaler_eps_mode` "std_clamp" (alpha uses the struct defaults: 0.1 /
"variance_offset"), `quantile_levels` 21 levels 0.01..0.99 step 0.05 (alpha:
5 levels 0.1/0.25/0.5/0.75/0.9). Identical: `num_layers` 24, `group_every_n`
3, `num_heads` 8, `mlp_hidden_dim` 2048, `patch_size` 32, `dropout` 0.1,
`scaler_use_arcsinh` true.

Checked every differing field against `crates/t0-core/src/config.rs` and
`crates/t0-core/src/scaler.rs`: all four are already config-driven
(`T0Config` deserializes them, `CausalScaler::new` already branches on
`eps_mode != "std_clamp"`, `T0Config::n_quantiles()` reads
`quantile_levels.len()`, `head_dim()` divides by `num_heads` not a
hardcoded width). No new ops needed — beta is a pure weights+config swap.

    --config ~/Code/idle-intelligence/models/hf/theforecastingcompany/t0-beta/config.json

Result: worst-case quantile max-abs error 2.503395e-6 (gate <=1e-4, alpha's
worst case was 1.192093e-6 — same 1e-6 order of magnitude, well inside the
gate).

## 3. Export + drift

```
for q in f16 q8_0 q4_0; do
  ./target/release/t0-cli export-gguf \
    --weights .../t0-beta/model.safetensors --config .../t0-beta/config.json \
    --quant $q --out fixtures/beta/gguf/t0-beta-$q.gguf
done
for q in fixtures/beta/gguf/t0-beta-f16.gguf fixtures/beta/gguf/t0-beta-q8_0.gguf \
         fixtures/beta/gguf/t0-beta-q4_0.gguf int8-theirs; do
  ./target/release/t0-cli drift --weights-f32 .../t0-beta/model.safetensors \
    --config .../t0-beta/config.json --quant $q --cases 54 --seed 42
done
```

Sizes: f16 511.3 MB (0.500x), q8_0 275.3 MB (0.269x), q4_0 149.5 MB
(0.146x) of the 1022.5 MB F32 safetensors. Drift table in
`docs/BENCHMARKS.md`. Wall time: export-gguf runs were seconds each; the
4-quant drift loop (54 cases x context 512 x horizon 96, forward pass at
embed_dim 1024) took under 10 minutes total on `ndarray`/CPU.
